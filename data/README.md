# Dados

`penguins.csv`: Palmer Penguins, 344 pinguins de três espécies observados no arquipélago Palmer, na Antártida.

| Coluna | Descrição |
|---|---|
| `species` | Adelie, Chinstrap ou Gentoo (o que queremos prever) |
| `island` | Ilha onde o animal foi observado |
| `bill_length_mm` | Comprimento do bico |
| `bill_depth_mm` | Altura do bico |
| `flipper_length_mm` | Comprimento da nadadeira |
| `body_mass_g` | Massa corporal |
| `sex` | Sexo |

Alguns registros têm valores vazios. Os exemplos removem essas linhas antes de treinar.

Fonte: Gorman KB, Williams TD, Fraser WR (2014), via pacote [palmerpenguins](https://allisonhorst.github.io/palmerpenguins/). Licença CC0.
